# Nexus upload kit — MyVoiceZoo Together 1.0.0

- **Mod name:** MyVoiceZoo Together - Steam Co-op
- **Author:** Bars
- **Version:** 1.0.0
- **Main file display name:** MyVoiceZoo Together 1.0.0
- **Main file summary:** Initial release. Steam co-op with shared zoo progress, animal recordings, visible players and native settings controls.
- **Installation:** Manual. Extract the download and put MVZ.MP.dll in MyVoiceZoo/Mods.

## Upload materials

1. Upload `MyVoiceZoo-Together-1.0.0.zip` as the main mod file. It contains only the DLL and README.
2. Paste `short-description.txt` into the summary field.
3. Paste `description.bbcode.txt` into the description's BBCode editor.
4. Use `myvoicezoo-together-cover.png` for the main image and `myvoicezoo-together-icon.png` where a square image is useful. Both derive from a real local co-op session; Bars and Juniper are the demonstration player names. Only cropping and title typography were added.
5. Use `changelog-1.0.0.txt` for the initial changelog. Add MelonLoader as a requirement.

The upload kit itself is authoring material, not the player download. Nothing has been uploaded or published by this preparation task.

Nexus reference: [Best Practices for Mod Authors](https://help.nexusmods.com/article/136-best-practices-for-mod-authors).
